## NJUPT API

使用 Rust 构建的 NJUPT 系列 API。

支持的API:

教务系统（正方 `jwglxt.njupt.edu.cn`，只读 + 内存缓存）：

- 学生课表（按学年学期）
- 成绩查询（可按学年学期筛选）
- 成绩分项（平时/期末等；南邮当前多为仅总评）
- 考试安排（正考 / 补考 / 缓考）
- 已选课程名单
- 学生个人信息
- 登录：校内直连 SSO / 校外经 Enlink WebVPN

学生卡：

- 查询账户余额

接口说明：

新版本 webvpn 登陆使用 Enlink

新版本 sso 登陆依然使用 cas i.njupt.edu.cn/cas 旧版本 202.119.226.235/cas

旧一卡通使用 yktapp

无法支持校园卡充值，电费查询等api。
电费查询需要手动获取token，不如直接打开小程序。
